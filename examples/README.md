# Examples

These are redacted versions of real-world, infrastructure-specific skills. They show how to build skills for your own environment — things like SSH access to network devices, Docker-based local testing environments, and other operational tooling.

The skills in this directory are **not** meant to be installed directly. Instead, use them as templates and inspiration for creating your own infrastructure-specific skills.

## What's Here

- **firewalla-ssh/** — A skill for SSH-ing into a network router and running diagnostics. Shows how to encode connection details, common commands, and database access patterns into a skill.
- **local-test/** — A skill for spinning up a local Docker environment that mirrors a production VPS. Shows how to capture deployment architecture, verification checklists, and troubleshooting steps.
- **sample-project-claude-md.md** — Example of a project-level CLAUDE.md, showing the kind of context you'd add per-repository (vs. global instructions).
